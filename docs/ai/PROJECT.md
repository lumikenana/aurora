# GameAI - 项目概要

## 项目名称

GameAI - Windows 桌面 AI 游戏助手

## 项目定位

本地优先的智能游戏助手，为 PC 游戏玩家提供实时 AI 辅助。

## 产品目标

- 让 AI 成为游戏玩家的实时助手
- 提供即时的游戏知识、策略建议
- 支持语音快速交互，不打断游戏体验
- 所有核心能力集成在单个 EXE 中，开箱即用

## 核心用户交互

1. **全局快捷键呼出** - 随时按下快捷键呼出文本输入框提问
2. **语音唤醒** - 通过唤醒词"Hey GameAI"唤醒
3. **Push-To-Talk** - 按住说话，松开识别
4. **连续语音对话** - 支持多轮连续语音交互
5. **按需截图分析** - AI 可以主动截图分析当前游戏画面
6. **游戏上下文理解** - 理解当前游戏状态和历史对话
7. **提供游戏知识和策略建议** - 针对具体游戏给出专业建议
8. **[未来] 主动 Coach Mode** - AI 主动观察并实时给出指导

## 当前技术栈

- **核心语言**: Go
- **桌面框架**: Wails v2
- **系统层**: Windows API (via golang.org/x/sys)
- **唤醒词**: openWakeWord (本地检测)
- **语音识别**: 火山引擎流式语音识别 2.0 (ASR)
- **语音合成**: 火山引擎 TTS
- **大语言模型**: LLM API (Provider 抽象)
- **本地存储**: SQLite

## 核心设计原则

1. **单一可执行文件** - 最终只发布 `GameAI.exe`
2. **零依赖安装** - 用户无需安装 Python / Node.js / Docker
3. **单进程架构** - 所有模块运行在同一进程
4. **无本地 HTTP 服务** - 模块之间直接函数调用通信
5. **Provider 抽象** - LLM/ASR/TTS 可换厂商，不绑定具体实现
6. **GamePlugin 抽象** - 支持多游戏接入，不耦合特定游戏
7. **分层唤醒** - 本地唤醒词检测 + 云端 ASR，节省流量和延迟
8. **按需视觉分析** - 不持续发送画面，只在需要时截图
9. **清晰边界** - Go 负责核心逻辑，前端只负责 UI
10. **平台隔离** - Windows 特定代码通过条件编译隔离

## 明确"不做什么"

- ❌ 不做微服务拆分
- ❌ 不要求用户部署多个服务
- ❌ 不要求用户运行本地 HTTP 服务
- ❌ 不做云服务（产品是本地桌面应用）
- ❌ 不做游戏外挂 / 作弊
- ❌ 不破解游戏
- ❌ 不碰游戏内存
- ❌ 不提供网络游戏代打

## 当前支持范围

- 项目骨架初始化 ✓
- 基础框架搭建 ✓
- 配置管理 ✓
- 日志系统 ✓
- 错误处理 ✓
- 平台抽象层 ✓
- 系统托盘 ✓
- Wails 基础窗口 ✓

AI 能力、语音、截图、游戏支持均未实现。

- 游戏数据自动统计
- 多游戏配置切换
- 回放记录和分析
- 社区分享游戏攻略
